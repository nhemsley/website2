# Experiment: D3.js Bubble Chart

**Status**: In Progress  
**Pattern**: #1 Bubble Chart  
**Stack**: Svelte + D3.js + Vite

## Purpose

Interactive bubble chart for skill visualization with:
- Size = proficiency level
- Color = skill category
- Drag to rearrange
- Filter by category
- Hover tooltips

## Run

```bash
npm install
npm run dev
```

## Features

- [x] D3 force simulation
- [x] Draggable bubbles
- [x] Category color coding
- [x] Filter by category
- [x] Hover tooltips
- [ ] Responsive sizing
- [ ] Data from external source
